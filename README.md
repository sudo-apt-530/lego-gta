# Кирпичный город

3D-игра в браузере про город из кирпичиков в стиле наборов LEGO City (фан-проект).

В городе есть полицейский участок, больница, жилые дома, стройка и три магазина: пиццерия, супермаркет и ювелирный. Жители — минифигурки, профессию видно по одежде. Каждые 40–60 секунд что-то случается: ограбления магазинов, перестрелка банд, побег из участка или бунт с табличками. В каждом происшествии 7–10 участников с битами, ломами, пистолетами, MAC-10 и АК-47.

## Как запустить

Открой `index.html` (или `lego-city.html`) в браузере. Нужен интернет: Three.js, шрифты и сетевая библиотека грузятся с CDN.

## Сетевая игра (до 5 человек)

Все, кто открыл игру, попадают в один город, по 5 человек в каждом. Шестой игрок попадает во второй город, и так далее.

Чтобы играть только с друзьями, впишите всем одинаковый **код города** на стартовом экране, например `druzya`. Код может состоять из латинских букв, цифр, `-` и `_`. Там же вводится своё имя для других игроков.

Код можно передать и ссылкой: `index.html#city=druzya`.

В сеть игра входит после выбора профессии. В списке игроков под здоровьем видно «Сетевая игра · N из 5» и название города. Если там написано «Сеть недоступна», значит, браузер не смог подключиться к брокеру, и игра идёт в одиночку.

Как это работает: город для всех ведёт страница одного из игроков. Если он выходит, его роль сама переходит к другому. Игроки обмениваются данными через бесплатный публичный MQTT-брокер (`broker.emqx.io`, запасной — `broker.hivemq.com`). Своего сервера не нужно, но канал публичный: в игру может зайти любой, кто знает код города, поэтому не пишите в имени ничего личного.

На claude.ai вместо брокера используется встроенная комната Claude.

## Профессии

- **Полицейский** — ловит бандитов, арестовывает сдавшихся, задерживает митингующих.
- **Бандит** — грабит кассы и получает долю, когда банда уходит от полиции.
- **Медик** — лечит раненых за деньги, бандиты его не трогают.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | ходить |
| Shift | бежать |
| Мышь, клик | прицел, удар или выстрел |
| 1–6 | оружие |
| E | арестовать, уговорить, вылечить, ограбить кассу |
| Колесо мыши | приблизить камеру |
| N | вызвать происшествие сейчас |
| L | законы города |
| Esc / P | пауза |

## Законы

1. Не нападай на мирных жителей — ★
2. Не убивай мирных жителей — ★★
3. Не трогай полицию — ★★–★★★
4. Не стреляй, когда нет угрозы — ★
5. Не грабь магазины — ★
6. Не бей сдавшихся — ★

С одной звездой полиция пытается задержать и штрафует, с двумя и больше открывает огонь.
